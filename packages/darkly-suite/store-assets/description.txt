HOW IT WORKS

Install Darkly Suite and dark mode is ready across Gmail, Google Sheets, and Google Docs. Each app gets its own toggle button in the toolbar for instant on/off control.

Open the settings panel in any app to configure that app's dark mode independently. Set scheduling, choose a theme preset, enable Preserve Grid Colors in Sheets or Preserve Page Colors in Docs — each app remembers its own preferences.

Your preferences sync across devices using Chrome's built-in sync. No account required for preference syncing.

WORKS WITH STANDALONE DARKLY EXTENSIONS

Already using Darkly for Gmail, Darkly for Sheets, or Darkly for Docs? Darkly Suite detects installed standalone extensions and prevents double-injection. The first extension to load on a page claims it, and the other gracefully steps aside. You can transition to the Suite at your own pace.
