# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any Darkly extension or the landing site, please report it privately by emailing **admin@darklysuite.com**. Do not file a public GitHub issue.

We aim to acknowledge reports within 48 hours and to coordinate a fix and disclosure timeline with the reporter.

## Scope

- Chrome extensions: gmail-darkly, sheets-darkly, docs-darkly, darkly-suite, browse-darkly
- Landing pages and payment backend: darklysuite.com and per-product subdomains
- Cloudflare Workers and D1 database under the same account

## Out of scope

- Theft of credentials a user has voluntarily entered into a phishing site that mimics Darkly
- Issues in third-party services we depend on (Stripe, Google OAuth, Cloudflare) — please report those directly to the vendor
